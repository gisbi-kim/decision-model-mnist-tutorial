# MNIST Visual Decision Model — 실험 노트

한국어 튜토리얼 웹사이트. 세 숫자와 자연어 지시를 입력받는 decision model의 데이터, 학습, 평가와 한계를 설명한다.

- 실험 코드: https://github.com/gisbi-kim/mnist-visual-decision-lab
- 공개 데모: https://huggingface.co/spaces/giseopkim/mnist-visual-decision-lab
- `index.html`을 브라우저에서 열거나 정적 서버로 제공한다. 그래프의 고정 예측 값은 저장된 결과이며 실시간 모델 호출이 아니다.
